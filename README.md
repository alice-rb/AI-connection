# 🤖 Python LLM AI Utilities

This repository contains Python scripts to connect to a **Large Language Model (LLM)** and interact with a selected AI (e.g., **Gemma AI**), providing multiple functionalities like **translation, image generation, audio transcription**, and more.

---

## 🗂️ Files

### 1️⃣ `llm_connection.py`
This script handles the connection from Python to the LLM and links it to the selected AI.

**✨ Main features:**
- Connect to your chosen LLM
- Select an AI for interactive use
- Send prompts and receive responses programmatically

---

### 2️⃣ `ai_utilities.py`
This script provides additional utility functions for tasks beyond text interaction.

**✨ Main features:**
- 🌐 Translate text between languages  
- 🖼️ Generate images from prompts  
- 🎙️ Transcribe audio files  
- 🔧 Extendable to other AI-powered functionalities
